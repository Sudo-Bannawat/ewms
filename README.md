# ระบบงานค้าง (Pending Tasks)

ระบบงานค้าง คือระบบช่วยติดตามงานที่ยังไม่เสร็จและครบกำหนดส่ง ภายในหน่วยงาน โดยสมาชิกสามารถสร้างงาน กำหนดผู้รับผิดชอบ กำหนดส่ง และสถานะของงานได้ และระบบจะแจ้งเตือนผ่าน Telegram เมื่องานใกล้ถึงกำหนดหรือเกินกำหนด สร้างจากคชสารเว็บเฟรมเวิร์ค (Kotchasan 6.0.0 / GCMS 6.9.0)

## ความต้องการของระบบ

- PHP 5.6 ขึ้นไป
- ext-mbstring
- PDO Mysql

## การติดตั้งและการอัปเกรด

1. ให้อัปโหลดโค้ดทั้งหมดจากที่ดาวน์โหลด ขึ้นไปบน Server
2. เรียกตัวติดตั้ง http://domain.tld/install/ (เปลี่ยน domain.tld เป็นโดเมนรวมพาธที่ทำการติดตั้งไว้) และดำเนินการตามขั้นตอนการติดตั้งหรืออัปเกรดจนกว่าจะเสร็จสิ้น
3. ลบไดเร็คทอรี่ install/ ออก

## การใช้งาน

- เข้าระบบเป็นผู้ดูแลระบบ : `admin@localhost` และ Password : `admin`
- เมนู **งานค้าง** สำหรับสมาชิกที่ล็อกอิน: สร้างงานใหม่ / รายการงาน / ตั้งค่างานค้าง (เฉพาะผู้ดูแลระบบเท่านั้น)
- ผู้ดูแลระบบสามารถมอบหมายผู้รับผิดชอบ กำหนดความสำคัญ และแก้ไข/ลบงานทุกคนได้

## การแจ้งเตือนผ่าน Telegram

1. ตั้งค่า Bot Token ชื่อผู้ใช้บอท และ **Telegram Chat ID** ของผู้รับ (ตัวเลข เช่น `123456789` หรือ `-1001234567890` สำหรับกลุ่ม/ช่อง) ที่ **ตั้งค่า > Telegram** แล้วกดปุ่ม **Test** เพื่อทดสอบการส่ง
2. สมาชิกกรอก **Telegram Chat ID** ที่หน้า "ข้อมูลส่วนตัว"
3. ตั้งค่า **รหัสลับสำหรับเรียกใช้ cron** และจำนวนวันแจ้งเตือนล่วงหน้าที่ **ตั้งค่า > ตั้งค่างานค้าง**
4. ตั้ง Cron บน Server ให้เรียก `cron_tasks.php` เป็นประจำ เช่น ทุกนาที

```
* * * * * curl -s "https://domain.tld/cron_tasks.php?secret=YOUR_SECRET_KEY" > /dev/null 2>&1
```

ระบบจะทำเครื่องหมายงานที่เกินกำหนดเป็น `overdue` และส่งข้อความเตือนไปยังผู้รับผิดชอบเมื่องานเหลือจำนวนวันถึงกำหนด (ตามที่ตั้งไว้) จนกว่างานจะถูกทำเครื่องหมายว่าเสร็จสิ้น

## ตารางฐานข้อมูลเพิ่มเติม

- `{prefix}_tasks` — ข้อมูลงานค้าง (หัวข้อ, รายละเอียด, ผู้รับผิดชอบ, กำหนดส่ง, สถานะ, ความสำคัญ)
- `{prefix}_task_notifications` — ประวัติการแจ้งเตือน (ใช้กันซ้ำการแจ้งเตือน 24 ชั่วโมง/งาน)

## ข้อตกลงการนำไปใช้งาน

- สามารถนำไปใช้งานส่วนตัวได้
- สามารถพัฒนาต่อยอดได้
- มีข้อสงสัยสามารถสอบถามได้ที่บอร์ดของคชสาร https://www.kotchasan.com
- ต้องการให้ผู้เขียนพัฒนาเพิ่มเติม ติดต่อผู้เขียนได้โดยตรง (อาจมีค่าใช้จ่าย)
- ผู้เขียนไม่รับผิดชอบข้อผิดพลาดใดๆในการใช้งาน
- ห้ามขาย ถ้าต้องการนำไปพัฒนาต่อเพื่อขายให้ติดต่อผู้เขียนก่อน (เพื่อบริจาค)
